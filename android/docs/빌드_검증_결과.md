# Android 개발 버전 검증 결과

검증 기준일은 2026년 10월 10일이다. 대상 버전은 0.1.0-night-alpha다.

- APK 전체 컴파일 및 debug 패키징 성공.
- 정책 안전성 테스트 23개와 센서 입력 품질 테스트 4개, 총 27개 통과. 실패·오류·건너뛰기 0개.
- Android Lint 오류 0개. 라이브러리 및 빌드 도구 신규 버전 안내 경고 6개가 남아 있다.
- 최종 APK 권한 검사에서 알림·foreground service·specialUse 및 앱 내부 동적 수신기 보호 권한만 확인.
- 카메라·마이크·인터넷·wake lock·저장소·접근성 권한 없음.
- Gradle 배포 파일 SHA-256 고정. APK SHA-256은 배포 파일과 함께 저장.
- 현재 APK는 개발용 debug 서명 버전. 공개 배포 버전 아님.

실제 S26 Ultra의 설치·재생 제어·화면 잠금·제조사 전원 관리·순전력 절감은 아직 검증하지 않았다. USB 연결 기기는 확인되지 않았으며, 실제 기기 테스트와 화면 시각 검증을 실행하지 않았다. 스마트워치 연동·실제 수면 추정은 구현하지 않았다.

이번 자동 테스트는 세션 교체, 항목 변경, 사용자 수동 정지, 센서 누락·공백, 시간 역행, 정지 요청 경합, 재시도 상한, 복구 기한, 재시작 후 소유권 폐기, 최대 재생시간과 센서 장애 분리, NaN·무한대·제로 센서 입력 등을 검증했다. 실제 앱의 OS 제어 성공을 입증하는 테스트와는 구분한다.
