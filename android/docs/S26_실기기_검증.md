# S26 Ultra 실기기 검증 기록

대상 모델은 사용자 확인 Samsung S26 Ultra 512 GB다. Android/One UI 버전과 스마트워치 정보는 아직 확인하지 않았다. 아래는 앞으로 수행할 검증이며 완료 기록이 아니다.

## 먼저 확인할 항목

- 설정 → 휴대전화 정보 → 소프트웨어 정보에서 Android/One UI 버전 확인.
- 자주 사용하는 미디어 앱 이름과 버전 확인.
- 스마트워치 사용 여부와 모델 확인.
- 알림 접근 및 SleepSense 알림 허용.

## 2분 기능 확인

1. 사용 앱에서 재생 시작 → SleepSense에서 같은 대상 선택.
2. 2분 기능 확인 시작 → 미디어 앱으로 돌아감.
3. 약 2분 + 15초 이후 재생이 실제로 멈추는지 확인.
4. 60초 안에 되돌리기를 눌러 같은 콘텐츠가 재생되는지 확인.
5. 수동으로 정지한 콘텐츠는 SleepSense가 다시 켜지 않는지 확인.
6. 정지 뒤 콘텐츠 또는 대상 앱을 바꾸면 되돌리기로 새 콘텐츠를 재생하지 않는지 확인.

## 야간 조건

- 불을 완전히 끄고 화면 잠금 여부를 바꿔 시험.
- 스피커, Bluetooth 이어폰, 유선 연결을 사용하는 조합으로 시험.
- 무활동 15분 시험에서 중간 기기 이동이 시간을 새로 시작하는지 확인.
- 센서 공급이 멈추면 기존 무활동 누적이 초기화되는지 확인.
- 권한 취소와 서비스 강제 중지 이후 추가 명령·자동 재시작이 없는지 확인.
- 보호 종료 뒤 지속 알림 및 센서 사용이 끝나는지 확인.

## 기기별 기록

각 시험은 앱 버전, 출력 기기, 화면 상태, 배터리 설정, 시작 시각, 정지 결과, 복구 결과, 실패 이유를 기록한다. 콘텐츠 제목·URL·알림 본문이나 센서 원본은 기록하지 않는다.

8시간 야간 동작과 SleepSense 미사용/사용 소비 비교를 완료하기 전에는 실제 수면 감지 성공이나 배터리 절감량을 확정하지 않는다.
