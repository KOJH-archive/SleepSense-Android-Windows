# SleepSense Windows 0.1.0 · 야간 보호 알파

Windows 11 x64용 첫 개발 버전입니다. 빛이 없는 방에서 쓸 수 있는 재생 보호부터 구현했습니다. 아직 생체 신호나 눈 감김으로 수면을 판별하는 버전은 아닙니다.

## 실행

배포 ZIP을 풀고 **SleepSense 폴더 안의 SleepSense.exe**를 실행하세요. Python 설치가 필요 없습니다. `_internal` 폴더는 실행 파일과 함께 있어야 합니다. 현재 개발용 실행 파일은 코드 서명되지 않았습니다.

1. 동영상 또는 음악을 재생합니다.
2. SleepSense에서 재생 중인 앱을 선택합니다.
3. 입력이 없는 시간(기본 45분), 최대 재생 시간(기본 사용 안 함)을 선택합니다.
4. **오늘 밤 보호 시작**을 누릅니다. 시작 이후의 시간부터 계산합니다.
5. 재생을 멈추기 전 15초 동안 예고합니다. 이때 입력하거나 **계속 재생**을 누르면 취소합니다.
6. 일시정지가 확인된 뒤 60초 안에 **되돌리기**를 누르면 같은 재생 항목만 다시 재생합니다.

`2분 뒤 실제 일시정지 시험`은 선택한 앱을 실제로 멈춥니다. 2분에 15초 예고가 추가됩니다. 시험 중 예고를 취소하거나 되돌리면 시험은 종료됩니다. 일반 보호는 첫 취소/되돌리기 뒤 15분을 쉬고 새 보호 시간을 계산하며, 두 번째 취소/되돌리기로 종료됩니다.

창을 닫으면 작업 표시줄의 숨겨진 아이콘에서 계속 실행됩니다. 아이콘을 클릭하면 창이 열리고 우클릭 메뉴로 완전히 종료할 수 있습니다. 트레이가 제공되지 않는 환경에서는 창을 닫으면 종료합니다. Windows 로그인 시 자동 실행되지 않습니다. 다시 실행하거나 PC가 절전에서 깨어나면 보호를 수동으로 시작하세요.

## 정확히 무엇을 제어하나요?

Windows 미디어 제어에 재생 상태를 제공하고 일시정지를 지원하는 앱만 나타납니다. 앱이 목록에 없다면 이 버전으로 제어할 수 없습니다. 브라우저의 여러 재생 탭을 구별할 수 없는 경우 제어를 거부합니다. 다른 미디어 세션이 추가/제거되거나 대상의 재생 항목·메타데이터가 변경되면 보호를 종료합니다. 음악이 다음 곡으로 넘어갈 때도 앱의 변경 알림에 따라 종료될 수 있습니다. 여러 곡을 계속 보호하는 기능은 추후 별도 검증이 필요합니다.

음소거, 스페이스 키, 전역 재생/정지 토글, 프로세스 종료를 사용하지 않습니다. 일시정지는 해당 앱에 대한 요청이며, 스트리밍·CPU 사용을 앱이 실제로 줄이는지는 앱별로 다릅니다. 실패 시 자동 제어를 중단합니다. 미디어 상태 알림이 오면 되돌리기 권한도 보수적으로 취소할 수 있습니다. Windows API는 모든 외부 조작의 원인을 알려주지 않으므로 사용자 조작과의 극히 짧은 경합을 완전히 증명할 수는 없습니다.

키보드·마우스 입력이 없다는 것은 잠들었다는 뜻이 아닙니다. 영상을 가만히 시청해도 시간이 흐릅니다. 최대 재생 시간은 입력 여부와 관계없이 적용되지만 예고 중 입력하면 취소됩니다. 화면 자동 끄기, 시스템 절전, 카메라·마이크·웨어러블·NPU 감지는 이번 배포에 포함되지 않습니다. LG그램의 저조도 카메라를 수면 판정에 사용하기 전 품질 검증과 개인별 보정이 필요합니다.

## 개인정보

실행 중 센서 영상·음성을 수집하지 않습니다. 외부 통신, 분석 서버, 콘텐츠 제목·URL 기록, 입력 내용 기록, 설정 저장을 사용하지 않습니다. Windows가 제공하는 앱 식별자와 재생 상태, 현재 로그인 세션의 마지막 입력 이후 시간만 메모리에서 처리합니다. 실행 시마다 설정은 기본값으로 돌아갑니다.

## 개발 및 검증

Python 3.12 x64, PySide6 6.9.3, PyWinRT 3.2.1, PyInstaller 6.16.0. 의존성은 `requirements.txt`와 `requirements-lock.txt`에 고정했습니다.

개발 환경에서 `python -m unittest discover -s tests -p "test_*.py" -v`로 안전성 테스트를 실행하고 `python main.py`로 앱을 실행합니다. 최상위 `.work/build_windows.ps1`로 배포 폴더를 생성할 수 있습니다. 테스트는 실제 사용자의 재생에 명령을 보내지 않습니다.

Windows API: [미디어 세션](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssession), [마지막 입력 조회](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getlastinputinfo), [Python WinRT](https://pywinrt.readthedocs.io/en/latest/). 의존성 사용 조건은 배포의 `THIRD_PARTY_NOTICES` 폴더에서 확인할 수 있습니다. Qt LGPL 사용 시 배포한 Qt DLL을 교체할 수 있도록 폴더 방식으로 배포합니다.
