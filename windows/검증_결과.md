# Windows 0.1.0 검증 결과

검증일: 2026-10-10. Windows 11 x64 (빌드 26200), Python 3.12.14.

- 보호 로직 22개와 미디어 명령 어댑터 9개, 총 31개 자동 테스트 통과.
- 다른 세션·다른 재생 항목·외부 상태 변경 뒤 복구 금지, 수동 정지 존중, 입력 관찰 실패, 절전 관찰 공백, 명령 반환 실패, 60초 복구 만료를 확인했습니다.
- 실제 Windows 미디어 API를 읽기 전용으로 연결했고 재생 세션 1개를 조회했습니다. 반복 조회 식별자 유지와 마지막 입력 조회를 확인했습니다.
- 배포용 `SleepSense.exe` 직접 실행: 화면 초기화와 백그라운드 WinRT 연결 성공, 종료 코드 0. 실제 사용자 미디어 제어 명령은 0회입니다.
- 한글 글꼴과 버튼·선택 상자 표시를 스크린샷으로 검토했습니다. 화면은 어두운 배경을 사용하고 작은 화면에서는 스크롤할 수 있습니다.
- 개발용 실행 파일은 서명되지 않았습니다. Python 런타임과 필요한 Qt DLL을 함께 배포하는 폴더 방식입니다.

LG그램에서의 실제 앱별 일시정지·되돌리기, 장시간 야간 운영, 배터리 소모 감소는 아직 검증하지 않았습니다. 생체 수면 판별, 카메라·마이크 분석, 화면 끄기 및 시스템 절전은 이 버전에 포함되지 않습니다.

## LG그램 확인 순서

1. ZIP을 풀고 `SleepSense/SleepSense.exe`를 실행합니다.
2. 평소 사용하는 브라우저나 음악 앱 하나만 재생하고 SleepSense 목록에서 선택합니다. 목록에 나타나지 않는 앱은 지원되지 않습니다.
3. `2분 뒤 실제 일시정지 시험`을 실행합니다. 예고 중에는 입력하지 말고 실제 재생이 멈추는지 확인합니다.
4. 멈춘 뒤 60초 안에 `되돌리기`를 눌러 같은 콘텐츠만 재생되는지 확인합니다.
5. 시험을 다시 실행해 15초 예고 중 입력하거나 `계속 재생`을 누르면 재생이 유지되는지 확인합니다.
6. 실제 야간 사용은 45분 입력 없음부터 시작하고, 너무 일찍 멈추면 시간을 늘립니다. 보호 시작 후 곡 전환이나 다른 앱의 미디어 세션 추가로 보호가 종료되는지도 확인합니다.

결과는 앱 이름과 성공/실패만 기록하면 됩니다. 콘텐츠 제목·화면·음성 자료는 필요 없습니다.
